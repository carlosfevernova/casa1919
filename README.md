# Casa 1919 — Cómo usar este proyecto

## Qué hay aquí

- **index.html** → La página web. Doble clic para verla en el navegador.
- **assets/marca-casa1919.png** → Tu imagen oficial de marca.
- **CLAUDE.md** → Contexto del proyecto para Claude Code (lo lee solo).
- **README.md** → Este archivo.

## Para verla rápido

Doble clic en `index.html`. Se abre en tu navegador. No necesita internet.

## Para seguir editándola con Claude Code

1. Abre PowerShell.
2. Entra a esta carpeta. Ejemplo:
   cd ~\Documents\Casa1919
3. Lanza Claude Code:
   claude
4. Como en esta carpeta está el archivo CLAUDE.md, Claude Code ya entiende
   todo el proyecto. Solo dile qué quieres. Ejemplos:

   - "lee index.html y cambia el correo de contacto a ventas@miempresa.mx"
   - "crea una pagina igual para el Reposado, con tonos un poco mas calidos"
   - "agrega una seccion de coctel con el mismo estilo"
   - "el logo se ve un poco grande en el footer, hazlo 20% mas chico"

Claude edita los archivos reales de tu carpeta. Cada cambio queda guardado
en tu disco.

## Consejo

Antes de cambios grandes, haz una copia de index.html (por si acaso):
   copy index.html index_respaldo.html
